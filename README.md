# Atividade Acadêmica sobre Construtores em Java.

## Sobre

Programa em Java que simula o cadastro de produtos, demonstrando o uso de
**construtores**, **sobrecarga** e **atributos/métodos estáticos**.

## Conceitos aplicados

- Construtor padrão e construtor com parâmetros (sobrecarga)
- Atributo estático compartilhado entre instâncias (`quantidadeTotal`)
- Método estático chamado diretamente pela classe
